# DR-NNN: Decision Title

| Field | Value |
| --- | --- |
| Status | Proposed |
| Version | 0.1.0 |
| Created | YYYY-MM-DD |
| Decision owner | Role or name |
| Gate | G0-G5 |
| Affected spec versions | IS/ES IDs and exact versions |
| Supersedes | Record ID or None |

## Decision

State the exact choice, effective scope, and behavior it authorizes.

## Context and evidence

Link evidence, benchmark results, source decisions, or constraints. Separate
verified facts from assumptions.

## Alternatives considered

| Alternative | Reason accepted or rejected |
| --- | --- |
| Option | Evidence-based rationale |

## Consequences

State implementation, migration, compatibility, publication, risk, and rollback
effects.

## Revisit conditions

List measurable events that require review or supersession.

## Approval

| Field | Value |
| --- | --- |
| Decision | Pending |
| Approved version | None |
| Approver | None |
| Decision date | None |
| Evidence | None |

The decision is unresolved until this table is complete and `Status` is
`Approved`.
