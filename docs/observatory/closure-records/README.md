# Closure-Record Index

Closure records prove that a work package met its approved intent and execution
definitions of done. Closure is distinct from release: a package can close
without public production activation, and a release cannot substitute for
unfinished work.

Use [TEMPLATE.md](TEMPLATE.md). Name records `CR-WPX.Y-vN.md`. Reopen work with a
new intent or execution version and a superseding closure record.
