# S7 Employer AI Compulsion Bootstrap Rubric

## Release state

This rubric is authored synthetic development evidence for
`bootstrap-rule-v0`. It is not a labeled benchmark, frozen production rubric,
or claim about any employer.

## Primary levels

| Index | Level | Bootstrap interpretation |
| --- | --- | --- |
| 0 | `none` | No eligible employer direction to use an AI tool |
| 1 | `optional` | Use is permitted or available and explicitly optional |
| 2 | `encouraged` | Use is recommended or positively encouraged |
| 3 | `expected` | Use is described as a normal work expectation or competency |
| 4 | `required` | Use, proficiency, training, or certification is mandatory |
| 5 | `monitored_or_enforced` | Use is tracked or tied to review, access, pay, promotion, discipline, or continued work |

The bootstrap document level is the highest qualifying passage level. This is
a synthetic-only provisional rule approved in DR-004, not the final conflict
policy.

## Mechanism flags

The primary level is mutually exclusive. Monitoring or audit, performance
evaluation, compensation or promotion, discipline or continued work, mandatory
training, tool or workflow specificity, and opt-out or accommodation remain
independent flags.

## Context masks

Negated, quoted, third-party, and historical-only passages remain in private
evidence but cannot escalate the bootstrap document level. Relevant language
with no recognized direction becomes ambiguous and also does not escalate.

## Authored examples

These examples are synthetic and intentionally short:

- `none`: "This role builds artificial intelligence products for customers."
- `optional`: "Employees may use approved AI tools, but use is optional."
- `encouraged`: "Team members are encouraged to use generative AI tools."
- `expected`: "Employees are expected to use AI assistants in daily work."
- `required`: "Employees must use the approved AI tool for this workflow."
- `monitored_or_enforced`: "Employee AI-tool use is tracked in performance review."

## Hard negatives

Product development, AI-company descriptions, customer or applicant
requirements, negated requirements, quoted policy language, historical-only
language, and general AI discussion must not escalate a document.

## Runtime boundary

Runtime input is normalized employer-authored text plus an opaque snapshot ID.
Source, employer, period, occupation, industry, jurisdiction, URL, collector,
and score fields are unavailable to the extractor.
